# Katali Lab

Pure-C, CPU-only inference engine for large MoE / hybrid-attention LLM packs, plus a Win32 chat UI. Windows binaries only — no source in this repo.

## Contents

- `katali-lab.exe` — CLI (inspect / bench / run / verify)
- `katali-lab-chat.exe` — Win32 chat GUI (spawns `katali-lab.exe` as a subprocess, so keep both files in the same folder)

## Quick start

```
katali-lab.exe --help
```

Or just double-click `katali-lab-chat.exe`, point it at a model pack, and start chatting.
